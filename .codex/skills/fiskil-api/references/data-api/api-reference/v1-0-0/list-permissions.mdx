# List permissions (/data-api/api-reference/v1-0-0/list-permissions)

Returns a list of Fiskil permissions.

## GET /permissions

**List permissions**

Returns a list of Fiskil permissions.

**Tags:** permissions, public

### Parameters

| Name | In | Type | Required | Description |
|------|----|------|----------|-------------|
| `industry` | query | string | No | The industry to filter on |
