# Start Exploring (/data-api/guides/getting-started/start-exploring)

Essential information to kick off with Fiskil



This page summarizes all the essentials you will need to know to kick off with Fiskil. Here you can find best practices and tips to set up your branding, integrate Fiskil and ingest data ASAP.

Create an account and start exploring Fiskil [#create-an-account-and-start-exploring-fiskil]

Contact the Fiskil team to get your account created, if you already have an account go ahead and login to the Console.

Create your API Keys [#create-your-api-keys]

In the Console you can generate new API keys, these credentials are required to access the platforms APIs. Creating a key can be found under **[Settings > API Keys](https://console.fiskil.com/data-api/settings/api-keys)**.

<Callout type="info">
  Tip: Be specific with your key naming and rotate the keys with each major
  product update, or after 90 days.
</Callout>

End Users [#end-users]

The End User entity within Fiskil represents your users, these can be consumers or businesses. The object is used for linking accounts held at institutions and compliance purposes - [Create an end user](/data-api/guides/getting-started/quick-start#3-create-an-end-user)

<Callout type="info">
  Tip: End Users are typically created when the user signs up to your
  application, or when you capture the users email.
</Callout>

Build your consent flow [#build-your-consent-flow]

Build and design a consent flow to connect your users data to your product. The flow is built for any use case and brand, allowing you to control the experience end-to-end.

Pull in data and start delivering new customer experiences Start pulling in data through our [Banking API](/data-api/api-reference) or our [Energy API](/data-api/api-reference).
